# splat-compass

スプラトゥーン3のプレイ映像を読み取り、試合の出来事を自分のPCに貯めていく道具です。貯まった記録から、「どんな状況で倒されやすいか」「勝った試合と負けた試合で何が違うか」を集計できます。

映像の処理は自分のPCの中だけで行います。動画や他のプレイヤーの名前は保存しません。

## 読み取れるもの

- 画面上部の8人のアイコン：生きている／倒されている／スペシャルが溜まっている
- 試合の始まりと終わり
- ルール（試合前の表示から。今はガチエリア・ヤグラ・ホコ・アサリ）
- 勝敗（試合後の WIN! / LOSE... から）
- マップ画面の塗りの割合（マップが出たとき。味方 ÷ (味方+敵) の面積）
- カウント（のこり〇〇）と、どちらの箱が塗られているか（ガチエリアでは確保している側）、ペナルティ（+〇〇）
- ヤグラ・ホコの位置とチェックポイント、アサリのゴールが開いているか
- 自分を倒したブキ（倒されたときの吹き出し）、マップ画面（出るたびに1枚保存し、場面の一覧に並べる）

自分の枠は試合ごとに違うので、右上の自分のスペシャルゲージが満タンになった時刻と、味方のアイコンがスペシャル準備の状態になった時刻を照らし合わせて決めます。一度もスペシャルが溜まらなかった試合は、自分が倒されたときの「復活まであと〇秒」の表示から推定します。どちらも無い試合は、自分についての集計から外します。

重い処理はしていないので、GPUは要りません。

## 必要なもの

- Python 3.10 以上
- `pip install -r requirements.txt`
- 1920x1080 の映像（キャプチャーボード、OBS の仮想カメラ、または OBS の録画）

## 入れ方と更新

最初の1回だけ、`git clone` で取ってきます。

```
git clone https://github.com/uma-pan/splat-compass
cd splat-compass
pip install -r requirements.txt
```

あとは `start.bat` をダブルクリックすれば、最新版に更新し、足りない部品を入れてから、読み取りと画面を始めます。カメラ番号が0以外のときは、同じフォルダに `camera.txt` を作って番号だけを書いてください（`start.bat` 自体を書き換えると、更新のときにぶつかります）。手で更新するときは、フォルダの中で `git pull` を実行します。

## 画面

`start.bat` で開く窓に、試合中の様子とまとめが1つにまとまっています。「試合中」タブの上部に、映像の入力、試合の読み取り、保存の状態が出ます。カウントをしばらく読めないと推定勝率は更新待ちになります。「小さくする」を押すと、試合中の表示だけの細い窓になり、ゲームの画面の上に出たままになります（pywebview が入っているとき。入っていなければブラウザで開きます）。試合が保存されたら「直前の試合を開く」で振り返りを見られます。

映像を読まずにまとめだけ見るときは `report.bat`（`python -m splat_compass.app`）を使います。

```
python -m splat_compass.app --camera 1        # カメラ1を読みながら画面を開く
python -m splat_compass.app --video 録画.mp4  # 録画を流して動作確認
python -m splat_compass.report "D:\Spla Capture"   # まとめを report.html に書き出す（録画のフォルダは最初の1回だけ）
```

「試合履歴」では日付・ルール・ステージ・勝敗・分類で絞り込めます。試合を開くと、振り返りを見たり、勝敗・ステージ・分類を訂正したりできます。上部の「集計の対象」はまとめに適用されます。「見返す場面」から録画フォルダを設定できます。

## 使い方

### その場で読む（キャプボ／OBS仮想カメラ）

OBS がキャプボを使っていると、ほかのソフトからは同じキャプボを開けません。OBS の「仮想カメラ開始」を押して、その仮想カメラを読ませるのが簡単です。

```
python -m splat_compass.live --list         # 使えるカメラ番号を調べる
python -m splat_compass.live --camera 1     # 番号を指定して開始
```

小さな窓に、人数、両チームのスペシャル準備数、自分がスペシャルを溜めてからの秒数が出ます。次のときは音と赤字で知らせます。

- 敵のスペシャル準備が2人以上
- 自分がスペシャルを溜めたまま20秒たった

試合が終わるたびに、記録を保存します。

### 録画をまとめて読む

```
python -m splat_compass.batch "D:\Spla Capture"            # まだ読んでいない録画を全部読む
python -m splat_compass.batch "D:\Spla Capture" --watch    # 新しい録画ができるたびに読む
python -m splat_compass.batch "D:\Spla Capture" --redo     # 新しい版で全部読み直す（前の記録は matches/_old に移す）
```

### 集計を見る

```
python -m splat_compass.analyze
python -m splat_compass.analyze --rule ガチエリア
```

### ガチエリアの打開を見る

エリアを相手に確保されてから確保し返すまでを「打開」の1回として、かかった時間・取られたカウント・成功した割合を、打開の始め方や撃ち合い、スペシャルの使い方ごとに比べます。

```
python -m splat_compass.area
```

### ヤグラ・ホコ・アサリの打開を見る

```
python -m splat_compass.objective
```

- ヤグラ・ホコ：画面上部の棒から位置を読み、相手に押されて中央を越えてから、中央まで戻すまでを打開1回とします。一番深く押された地点から少し戻った時点を「止めた」として、止めるまでの時間も出します。ホコを落として中央に戻ったもの（リセット）には印を付けます。
- アサリ：味方のゴールが割られてから閉じるまでを打開1回とします。
- 自分が倒した数：相手を倒すと画面の下に出る「〇〇 をたおした!」の行を、字の形で見つけて数えます（続けて倒すと行が重なって増えるので、増えた分を数えます）。
- ヤグラ・ホコのカウント：棒の下の「のこり〇〇」の吹き出しを、チームの色で探して読みます（吹き出しは左右に動き、重なっているときは読みません）。
- ヤグラ・ホコのチェックポイント：試合序盤の棒を重ねて目印の位置を見つけ、どちらがいつ通ったかを記録します。第1チェックポイントを先に取った側と、取るまでの秒数・勝率を出します。

### 勝率予測モデル（ガチエリア）

毎秒の試合の状態（経過時間、カウント差、確保状態、人数、スペシャル準備数）から勝率を予測するモデルを作ります。試合ごとに分けた交差検証（OOF）で精度を確かめ、OOF の予測を使って、倒された・スペシャル発動などの出来事の前後で勝率がどれだけ動いたかを出します。numpy だけで動き、GPU は要りません。

```
python -m splat_compass.winprob
```

勝率モデルは、試合が保存されるたび（その場の読み取りは1試合ごと、録画の読み込みは最後に1回）に自動で作り直されます。新しい試合ほど重く学習し、前のモデルが学習に使っていない新しい試合で新旧を比べて、悪くならなかったときだけ入れ替えます。作り直すたびの精度は `model_history.json` に残ります。

その場の読み取りでは、試合中に小窓の上へ今の勝率を大きく出し、その試合の勝率の動きを折れ線で描きます。ガチエリアはこのモデルで、ガチヤグラ・ホコ・アサリはまだ試合が少ないので、エリアの試合から「経過時間・カウント差・人数差」だけで作った簡単なモデルの値を「勝率の目安」として出します。試合後には「勝率が大きく動いた場面」を3つ出します。モデルは各自の記録で育つので、使う人ごとにその人向けのモデルになります。

### 見返す場面の一覧

勝率が大きく動いた場面、打開に失敗した・長引いた場面、スペシャルを持ったまま倒された場面、復活してすぐ倒された場面を録画から選び、ブラウザで再生できる一覧を作ります。録画のフォルダを指定します。

```
python -m splat_compass.scenes "D:\Spla Capture"
python -m splat_compass.scenes "D:\Spla Capture" --last 10   # 新しい10試合だけ
```

### 倒されたブキ

自分が倒されたときの吹き出し（「〇〇 で やられた!」）を保存し、「〇〇 で」の文字の形を見本と照らし合わせて、倒されたブキを数えます。同じブキなら文字の形は毎回同じなので、似た形をまとめて一度だけ名前を付ければ、あとは自動で分かります。

```
python -m splat_compass.killcam            # 名前の無いまとまりの一覧を作る
python -m splat_compass.killcam --report   # 倒されたブキの集計
```

名前は `splat-compass-data\killcam_labels.json` に「まとまりの番号: ブキ名」の形で書きます。

### 8人のブキ

試合の始めに、画面上部に並ぶ8人のアイコン（ブキの絵）を切り出して `splat-compass-data\weapons\` に残します。同じブキの絵に一度だけ名前を付ければ、あとは名前の付いた絵と見比べて自動で分かります。絵の形（輪郭）とブキの部分の色の両方を見るので、形の似たブキや、色違いの亜種も分けられます。まとめのページの「ブキ別の勝率」タブに、自分が使ったブキ、相手にいると負けやすいブキ、味方にいると勝ちやすいブキが出ます。

`weapons.bat` をダブルクリックすると、前の録画からのアイコンの切り出し → 名前を付ける画面 → まとめのページの作り直し、を順に行います。

- 名前を付ける画面では、同じブキと思われる絵が明るく、ほかの近い絵が暗く並びます。違うブキは押して暗くし、同じブキなのに暗い絵は押して明るくしてから、名前を入れて Enter を押します。明るい絵だけに名前が付きます。
- 「付けた名前を見直す」を押すと、名前ごとに、その名前の中で似ていない絵から順に並びます。間違っている絵を押して「選んだ絵の名前を消す」か、正しい名前を入れて Enter で付け直せます。

```
python -m splat_compass.weapons --extract   # 前の録画からアイコンを切り出す（録画のフォルダは前に指定したもの）
python -m splat_compass.weapons --label     # 名前を付ける画面
python -m splat_compass.weapons             # ブキ別の勝率を表示
```

名前は `splat-compass-data\weapon_labels.json` に保存されます。

その場の読み取りでは、試合開始から7秒ほどで8人のブキを読み、「試合中」タブに出します（黄色は候補どまり、赤は分からないブキ）。アイコンは1秒おきに5枚切り出し、ほかと一番似ている1枚を使うので、開始の演出やアサリ・ホコの印が重なった絵は避けられます。試合が保存されたら、そのまま名前を直せます。「ブキの確認」タブでは直近20試合の読み取りを並べて直せます。直した名前は次から見本として使われるので、まだ出たことのないブキも、ここで名前を付ければ覚えます。

### 世界のプレイヤーと比べる（stat.ink）

`statink.bat`（`python -m splat_compass.statink`）で、stat.ink の公開データ（世界中のプレイヤーが上げた試合結果）の直近30日分をダウンロードして集計します。取ってある日は飛ばすので、ときどき実行すれば新しい日だけ足されます。集計は `splat-compass-data\statink\summary.json` に残ります。

- 「ブキ別の勝率」タブに、相手にいたブキごとの「自分が負けた割合」と「世界でのそのブキの勝率」を並べます
- stat.ink の試合から学習したブキの強さで「編成だけで見た勝率」を出し、自分の試合の実際の勝率と比べます
- 振り返りで、倒した数を世界の同じブキの人の平均とも比べます

Xマッチとバンカラマッチのガチルールだけを使い、ブキごとの数字からは試合を上げた本人を除いています（stat.ink の説明より）。上げているのはやり込んでいる人が多いので、腕前は平均より高めに偏ります。データ: [stat.ink](https://stat.ink/)

### 試合ごとの振り返り

試合が終わるたびに、その試合を普段の自分（それより前の試合）と比べて、目立ったところを挙げます。復活直後のデス、スペシャルを持ったまま倒された場面、打開の速さなどを「試合履歴」から確認できます。推定勝率が大きく動いた場面では、変化をポイントで表示します。味方や相手の動き、カウントの変化も含まれます。

```
python -m splat_compass.feedback --last 5
```

### 動作確認

録画を、実際の速さでその場の映像のように流せます。

```
python -m splat_compass.live --video 録画.mp4
```

## 記録の保存先

既定ではホームフォルダの `splat-compass-data/matches/` に、1試合1ファイル（JSON）で保存します。保存先は `--data` か、環境変数 `SPLAT_COMPASS_DATA` で変えられます。

## 分かっている弱点

- 明るい背景の上では、倒されたアイコンを読み落とすことがある
- 1920x1080 以外の映像は、拡大縮小して読んでいる（精度は未確認）
- 日本語版の表示しか見本がない
- ナワバリバトルのルール表示の見本がまだない
- 自分の枠は、試合中に最初にスペシャルが溜まるまで分からない（その間はスペシャルの通知が出ない）


## 配る版（exe）

Python を入れていない人にも使ってもらうための版です。

- 作り方: `build.bat` をダブルクリック。`dist\splat-compass.zip` ができるので、これを配ります。
  作るときに、自分の記録からブキの見本（絵ではなく見比べに使う特徴だけ）と勝率モデルを同梱します（`python -m splat_compass.make_defaults`）。
- 使い方: zip を展開して `splat-compass.exe` を開き、「カメラを探す」から、スプラトゥーンの画面が映っているカメラを選びます。
  選んだカメラは覚えておくので、次からは開くだけで読み始めます。
- 記録は `ユーザーのフォルダ\splat-compass-data` に残ります。最初は同梱のブキの見本と勝率モデルを使い、
  自分の試合がたまると自分の記録で作り直したものに切り替わります。
